# App Store metadata v1.2 — en-US (copy-paste ready)

Prepared 2026-08-01 from the ASO competitive review
(aso-competitive-review-2026-08.md). This is the proposed **v1.2** US listing:
name, subtitle, and keywords are version-gated and ship with the v1.2
submission; promotional text can be pasted **today** without a release.
metadata.md remains the record of the live v1.1 listing until this ships.

Rationale in one line: every competitor in the niche maxes the 30-char title
with keywords while we used 13; the subtitle and keyword field are rebuilt so
no token is spent twice; the description stays honest and privacy-led because
that is the one claim nobody else in the niche can make.

## Name (30 chars max)

`Fable Bedtime Stories for Kids` (30)

- Keeps **"Fable Bedtime"** as the leading brand token — we continue to own
  the "fable bedtime" query outright against the Fable-name cluster.
- Buys the niche's two strongest phrases ("bedtime stories", "stories for
  kids") in the heaviest-weighted index field. Same convention as Oscar
  Bedtime Stories for Kids (30), Moshi Kids: Sleep, Relax, Play (30), Little
  Stories: Bedtime Books (29).

## Subtitle (30 chars max)

`Your child is the hero` (22)

- Benefit-led, true, and calm. Adds `child` and `hero` to the index.
- Deliberately repeats **nothing** from the name — the old subtitle's
  "Stories" would be a wasted duplicate under the new title.

## Category

- Primary: **Books** (was Lifestyle) — where the scale incumbent (Little
  Stories) lives and where a small-storefront chart position is reachable.
- Secondary: **Education** (was Books) — Oscar's and Lunesia's home.
- Still deliberately **not** the Kids category; the parent-as-operator
  reasoning in metadata.md stands unchanged.

## Keywords (100 chars max)

`sleep,children,fairy,tale,night,calm,toddler,storytime,ai,personalized,maker,read aloud,private,baby` (100)

Discipline applied:
- **No duplicates of name/subtitle tokens** (`bedtime`, `stories`, `kids`,
  `child`, `hero` are already indexed from those fields; Apple pools
  title + subtitle + keywords, so a repeat buys nothing).
- **No plural + singular pairs** (`tale` covers `tales`; `stories` in the
  title covers `story`). `children` stays because it is an irregular plural
  of an already-used token and a high-intent term in its own right.
- Phrase coverage via token combination: `personalized` + name →
  "personalized bedtime stories"; `maker` + name → "bedtime story maker";
  `fairy` + `tale` → "fairy tale"; `ai` + name → "ai bedtime stories";
  `read aloud`, `storytime`, `sleep`, `calm`, `night` carry the bedtime
  intent cluster; `toddler`/`baby` the age cluster; `private` the
  differentiator nobody else claims.
- Keeps the owner's standing decision (OWNER-ASKS #3) to retain
  kids/children/toddler-class terms despite the theoretical Kids-category
  reading; the listing remains explicitly parent-directed.

Description notes (why it changed):
- The description is not search-indexed on iOS — it is written for
  **conversion**, and it now sells the three things the research says no
  competitor can copy: on-device privacy (vs. Oscar/thefableapp/the AI long
  tail, all cloud), Personal Voice narration (vs. Lunesia's name-audio), and
  seven hand-written languages (vs. English-only rivals).
- "Completely private — unlike any other story app" is a comparative claim we
  can stand behind: every generating competitor found in the review runs in
  the cloud. If a genuinely on-device competitor appears, soften it.
- The legal-links block stays **in the description** — the 3.1.2 rejection
  of 2026-07-28 established that Apple wants the EULA link there, and every
  future description keeps it above the goodnight line.
- Fable+ marking (2.3.2) unchanged: "a new story every night" is only ever
  promised under the Fable+ heading or with a "With Fable+" prefix.
- No prices in the copy — metadata follows language, not storefront
  (the German-pricing lesson, OWNER-ASKS #2 a2). The paywall shows
  StoreKit's real localized price.
