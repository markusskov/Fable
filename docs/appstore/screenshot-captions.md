# Screenshot captions

One title and one subtitle per frame, for the five-frame set. Written to
match the app's OWN vocabulary in each language, so the caption and the
screen beneath it use the same words: Spanish says *cuento* (not
*historia*), French addresses the parent as *tu* (not *vous*), German says
*Geschichte*, and every "adventure" line reuses the exact wording of the
in-app button.

**Emphasis:** the word in **bold** is the one set in italic in the Figma
template, matching how English emphasises *your*, *every day*, *adventure*,
*Private*, *favorite*.

**Fit:** titles run to two lines and stay under ~40 characters; subtitles
are one line and stay under ~28. Counts are given so a longer translation
can be spotted before it wraps badly.

**No em dashes**, per the owner copy rule.

## English (revise two)

| # | Title | Subtitle |
|---|---|---|
| 1 | Tonight's story stars **your** child. | Uni**que** stories every time ← was "Uniqe" |
| 2 | Create a new story **every day**… | Set a theme for tonight |
| 3 | Or continue an **adventure**. | Continue on the story |
| 4 | **Private** by design. Of course. | Never sent, never collected ← was "Nothing leaves your phone" |
| 5 | Go back to your **favorite** story. | Read your favorites again |

Frame 4's subtitle changes for the same reason the app copy changed: Apple
device backups can include app data, so "nothing leaves your phone" claims
more than we control. The Norwegian set already says it the right way.

## Caveat worth stating

These were written by Claude, not by native speakers. They follow the app's
own shipped vocabulary and register, which is the part most likely to be
noticed by a customer (a caption that says *historia* over a screen that
says *cuento* looks careless). The phrasing itself would benefit from a
native read, and roadmap finding #7 already schedules exactly that pass for
French, Italian and Portuguese prose. If any single line should get a
native check before upload, make it Italian frame 1.
