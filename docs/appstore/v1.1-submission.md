# v1.1 submission dossier

The complete recipe for the multilingual release. Repo side runs first (a
session does it on the owner's word); ASC side is the owner's, in order.
Prerequisite: 1.0 is Released and live.

## Repo side (session)

1. `scripts/release.sh minor` — bumps to 1.1, build number up, writes the
   changelog from conventional commits, commits. Push the tag to publish
   the GitHub Release.
2. Build and upload the 1.1 binary (owner's Xcode Cloud workflow from main,
   or Product → Archive → Distribute locally — owner's call).

## ASC side (owner)

1. **Create version 1.1** on the iOS app page.
2. **What's New**: paste per language from `whats-new-1.1.md` (en, de, nb
   now; the four new localizations get theirs when created in step 3).
3. **Add four store localizations**: Spanish (Spain), French (France),
   Italian, Portuguese (Brazil). For each, paste name/subtitle/promotional
   text/description/keywords from `metadata-es.md`, `metadata-fr.md`,
   `metadata-it.md`, `metadata-pt-BR.md`. Descriptions already carry the
   EULA + privacy links (the 3.1.2 lesson) and no hardcoded prices.
4. **Screenshots per localization**:
   - iPhone 6.9": existing framed sets (owner's Figma exports) for en/de/no;
     for the four new languages either export framed versions or upload the
     raw staged sets from `docs/appstore/screenshots/<lang>/`.
   - iPad 13" (REQUIRED now that the binary declares iPad): raw sets ready
     in `docs/appstore/screenshots/ipad-13/<lang>/`, 2064×2752, all seven
     languages.
5. **Select the 1.1 build** once processed.
6. App Review notes: unchanged from 1.0 (paywall path via profile menu);
   the reviewer note in `metadata.md` still applies.
7. Submit. (Subscriptions are approved and live; nothing to attach.)

## After 1.1 is live (the launch chain, in order)

1. Blog posts from `docs/launch/blog-*.md` become site pages; press page
   from `press-kit.md`. Deploying `site/` publishes them (pages.yml).
2. Show HN per `docs/launch/show-hn.md` (owner submits).
3. Apple featuring nomination per `docs/launch/featuring-nomination.md`
   (owner pastes into ASC → Featuring).
4. Press emails (MacStories, 9to5Mac, parenting tech) per press kit.
5. Norway push: owner's network + communities, per the roadmap beachhead.
